# ฝนตกไหม — แผนที่ฝนล่วงหน้าแบบฟรี (PWA)

เว็บแอปหน้าเดียว (HTML + JS) เปิดได้บน iOS, Android, Windows, macOS และติดตั้งลงหน้าจอหลักได้แบบ PWA
ไม่มีโฆษณา ไม่เก็บเงิน ใช้เฉพาะข้อมูลสาธารณะที่ฟรีและอนุญาตให้ใช้ส่วนตัว/การศึกษา

โฟลเดอร์ `docs/` คือตัวแอปทั้งหมด (ตั้งชื่อ docs เพื่อให้ GitHub Pages เสิร์ฟจาก root URL ได้) (`index.html`, `app.js`, `styles.css`, `sw.js`, `manifest.webmanifest`, `icons/`)
ไฟล์ `RESEARCH.md` คือผลวิเคราะห์ APK ต้นฉบับและแหล่งข้อมูลที่ใช้ได้

## ฟีเจอร์
- เรดาร์ฝนย้อนหลัง 2 ชั่วโมง (RainViewer public API, 13 เฟรม ทุก 10 นาที)
- คาดการณ์ 60 นาทีข้างหน้า คำนวณในเครื่องด้วย optical flow (block matching) จากเรดาร์ 4 เฟรมล่าสุด
- พยากรณ์ฝนรายชั่วโมง 48 ชั่วโมงบนแผนที่ (Open-Meteo กริด 16×12 จุดต่อหน้าจอ)
- แตะจุด/ปุ่มตำแหน่ง → บอกว่า "ฝนจะถึงในอีกกี่นาที" หรือ "ฝนครั้งถัดไปเมื่อไร" พร้อมกราฟฝน 24 ชม.
- พื้นที่เสี่ยงน้ำท่วมขัง (ประมาณการ) จากความสูงภูมิประเทศ (Terrain Tiles) + ฝนคาดการณ์ 24 ชม. และระดับน้ำในแม่น้ำจาก Open-Meteo Flood API (GloFAS)
- เลเยอร์เสริม: เมฆ Himawari IR และฝนดาวเทียม IMERG จาก NASA GIBS
- ค้นหาสถานที่ (ภาษาไทย/อังกฤษ) และบันทึกรายการโปรดในเครื่อง
- แถบเวลาเล่นภาพ ย้อนหลัง → ตอนนี้ → คาดการณ์ → พยากรณ์
- ภาษาไทย/อังกฤษ, แผนที่มืด/สว่าง/OSM, ทำงานออฟไลน์บางส่วน

## รันทดสอบในเครื่อง
ต้องเปิดผ่าน http:// (ไม่ใช่ file://) เพราะ service worker และตำแหน่ง GPS ต้องการ
ตัวอย่างด้วย Python:

```bash
cd docs && python -m http.server 8765
```

แล้วเปิด http://localhost:8765/

## ขึ้น GitHub Pages (ฟรี)
1. สร้าง repository ใหม่บน GitHub (เช่น `rain-map`) **ห้าม** อัปโหลดไฟล์ .apk (มี .gitignore กันไว้แล้ว)
2. ในโฟลเดอร์นี้:

```bash
git init && git add docs README.md RESEARCH.md .gitignore && git commit -m "Rain map PWA"
```

```bash
git branch -M main && git remote add origin https://github.com/<ชื่อผู้ใช้>/rain-map.git && git push -u origin main
```

3. ไปที่ Settings → Pages → Source: "Deploy from a branch" → Branch `main`, Folder `/docs`
4. เปิด `https://<ชื่อผู้ใช้>.github.io/rain-map/`
5. บน iPhone: เปิดใน Safari → ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"; บน Android/Chrome: เมนู → "ติดตั้งแอป"

## ข้อจำกัดและข้อตกลงการใช้ข้อมูล
- RainViewer public API: ใช้ได้เฉพาะส่วนตัว/การศึกษา, ไม่มี nowcast จากผู้ให้บริการแล้ว, ซูมสูงสุด 7, จำกัด 100 คำขอ/IP/นาที (แอปจำกัดตัวเองที่ 80 และแคชไทล์ไว้ในหน่วยความจำ)
- Open-Meteo: CC-BY 4.0, ห้ามใช้เชิงพาณิชย์โดยไม่สมัครแผนเสียเงิน, ≤10,000 คำขอ/วัน/IP
- NASA GIBS และ Terrain Tiles: ไม่มีข้อจำกัด
- คาดการณ์ 60 นาทีและความเสี่ยงน้ำท่วมเป็นการประมาณการเชิงสถิติ ไม่ใช่คำเตือนทางราชการ

## โครงสร้างโค้ดสั้นๆ (`docs/app.js`)
- `refreshRadar()` เลือกช่วงไทล์ที่ครอบหน้าจอ (≤20 ไทล์, ซูม ≤7) ต่อเป็นภาพเดียวต่อเฟรม แสดงผ่าน `L.imageOverlay`
- `intensityOf()` แปลงสีจากพาเลตของ RainViewer (เบจ=ฝนปรอย, ฟ้า→น้ำเงินเข้ม=เบา→ปานกลาง, เหลือง→แดง=หนัก) เป็นค่าความแรง 0-1 แล้ว `recolor()` วาดใหม่ด้วยสเกลสีเดียวกับชั้นพยากรณ์และคำอธิบายสัญลักษณ์
- `computeNowcast()` → `estimateMotion()` หาเวกเตอร์การเคลื่อนที่ (ค้นหาทั่วภาพ + ปรับละเอียดรายบล็อก 12 px) แล้ว warp เฟรมล่าสุดไปข้างหน้า 6 ก้าว
- `refreshForecast()` ดึง Open-Meteo หลายพิกัดในคำขอเดียว → `renderForecastFrame()` วาด heatmap
- `refreshFlood()` ถอดความสูงจาก Terrarium PNG → ความสูงเหนือจุดต่ำสุดในรัศมี 2.5 กม. + ความชัน × ฝน 24 ชม.
- `renderStatus()` รวมผลเรดาร์/คาดการณ์/พยากรณ์/แม่น้ำ/ภูมิประเทศเป็นข้อความบนการ์ด
